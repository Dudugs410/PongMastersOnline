# Pong Masters Online (Windows)

This branch only holds the playable version of the game.

1. Click **Code > Download ZIP** on this branch.
2. Extract the zip.
3. Run `PongMastersOnline.exe` (if Windows warns you, click **More info > Run anyway**).

To play online, one player clicks **Host** and sends the join code shown on screen; the other types it in the **Join code or host IP** box and clicks **Join**.
